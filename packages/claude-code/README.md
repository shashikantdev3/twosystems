# twosystems for Claude Code

A Claude Code plugin that runs the stuck check, the fresh-start check and the honest receipt inside your sessions.

**Status:** planned for Sprint 2. See the [roadmap](../../docs/roadmap.md).

Once released, it will install straight from GitHub. The marketplace file at the repository root names the marketplace `twosystems`:

```
claude plugin marketplace add shashikantdev3/twosystems
claude plugin install twosystems@twosystems
```

Part of [twosystems](../../README.md), created by Shashikant.
