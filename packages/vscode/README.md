# twosystems for VS Code

A VS Code extension for GitHub Copilot users, also published on Open VSX for Cursor and Windsurf. It connects twosystems to Copilot's agent hooks, and shows the counter, suggestions and receipt in the editor, including for Claude Code sessions running in VS Code.

**Status:** planned for Sprint 4. See the [roadmap](../../docs/roadmap.md).

GitHub Copilot does not give hooks or extensions exact token counts, so receipts for Copilot sessions will be estimates.

Part of [twosystems](../../README.md), created by Shashikant.
