# 0004: Apache License 2.0

**Status:** Accepted, 18 October 2026

## Context

twosystems should be easy for companies to adopt, and the original authorship should stay visible as the code is reused.

## Decision

Release under the Apache License 2.0 with a NOTICE file that names the creator.

## Consequences

- Permissive use, including commercial use, with an explicit patent grant that companies prefer.
- Section 4(d) requires anyone distributing a derivative work to carry the attribution notices in NOTICE, so attribution travels with the code.
